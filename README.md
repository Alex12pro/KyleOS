# KyleOS

KyleOS is a web-based game and browser hub built for static hosting with Vercel support. It includes a main desktop-style interface, game launcher pages, Scramjet proxy assets, API routes, and Vercel configuration.

## Features

- Desktop-style main screen
- Game library loaded from `games.json`
- Individual play page support
- Scramjet proxy/runtime assets
- Vercel-ready configuration
- Static frontend files with lightweight API routes

Getting Started
Install dependencies:

npm install
Run locally with Vercel CLI:

npx vercel dev
Or serve the static files with any local web server.
